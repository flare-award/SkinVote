# SkinVote

Статическое веб-приложение для визуального просмотра и субъективной оценки скинов Minecraft. Работает полностью в браузере: файлы не загружаются на сервер.

Подходит для публикации на **GitHub Pages** — сборка бэкенда не нужна.

## Возможности

- Drag-and-drop папки или нескольких PNG, выбор через системный диалог
- File System Access API в Chromium (с деградацией в остальных браузерах)
- 3D-модель на [skinview3d](https://github.com/bs-community/skinview3d) (three.js)
- Поза по умолчанию без анимации, сброс камеры при смене скина
- Переключатель Slim / Wide, индивидуальный для каждого скина
- Четыре категории (красный, синий, лого, линзы) по шкале 1–10
- Итог как среднее с округлением до одного знака
- Таблица лидеров, подиум топ-3 и кнопка «открыть рядом с файлом»

## Запуск локально

Откройте папку любым статическим сервером, например:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Либо просто опубликуйте репозиторий через GitHub Pages (Source: Deploy from a branch → `/` root).

## Как пользоваться

1. Перетащите папку со скинами или выберите PNG-файлы.
2. Проверьте список валидных скинов и уберите лишнее.
3. Нажмите **Начать** — порядок перемешается один раз.
4. Оцените все четыре категории, затем **Следующий**.
5. После последнего скина откроется таблица лидеров.

Скины принимаются только в формате PNG и с размерами Minecraft: `64×32`, `64×64` или пропорциональные HD (`128×128`, `256×128` и т.д.).
